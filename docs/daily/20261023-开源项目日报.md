## 1. firecrawl —— 把任意网页变成 LLM 可用数据

**简介与定位**：面向 AI Agent 的网页数据抓取服务：输入 URL，输出干净的 Markdown、结构化 JSON 或截图。提供云服务与自托管两种形态，是当前"AI + 爬虫"赛道热度最高的项目之一（10 月 21 日单日 +461★）。

**核心功能亮点**：
- `/scrape` 单页提取、`/crawl` 全站递归抓取、`/search` 网页搜索一体化；

- 官方 SDK 覆盖 Python / Node / Go / Rust，MCP server 支持让 Claude、Cursor 等 Agent 直接调用。

**技术栈**：TypeScript (Node.js)、Playwright、Redis 队列、Docker 自托管。

**适用场景**：为 RAG 知识库批量摄取网页、Agent 的实时联网工具、竞品页面监控转 Markdown 归档。

## 2. Scrapling —— 自适应"打不死"的爬虫框架

**GitHub**：<https://github.com/D4Vinci/Scrapling>（Python，2024-10 创建）

**简介与定位**：自适应网页抓取框架，从单次 HTTP 请求到大规模并发爬取一条龙，内置反反爬能力，最大卖点是**页面结构变了也能自动重新定位元素**。

**核心功能亮点**：
- 元素自适应定位：DOM 变动后基于相似度自动找回目标元素，大幅降低爬虫"失明"维护成本；
- 三档取数模式：纯 HTTP（ StealthyFetcher 指纹伪装）/ 动态浏览器（基于 Camoufox 反指纹 Firefox）；
- 自动指纹、TLS 伪装、人机行为模拟等抗封锁选项开箱即用；选择器 API 兼容常用解析库。

**技术栈**：Python、Camoufox（反指纹 Firefox）、curl_cffi、lxml。

**关键指标（2026-10-23 实测）**：Star 89,295 / Fork 9,208 / 贡献者 41 / 当日有提交 / 最新 Release v0.5（2026-10-17，6 天前）。

**适用场景**：反爬严格的电商与内容站点采集、长期运行的监控型爬虫（页面改版不易崩）、个人开发者的数据采集项目。

**可靠性评估**：⭐⭐⭐⭐⭐ 开放 Issue 仅 16 个，是五者中响应状态最好的；v0.5 一周前刚发布，迭代节奏健康。BSD-3-Clause 宽松协议，商用友好，无风险。

**上手建议**：从 `Fetcher`（纯 HTTP）入手最轻量；被目标站拦截再逐级升级到 `StealthyFetcher` / `PlayWrightFetcher`；写定位表达式时直接用它的自适应选择器替代传统 XPath，收益最大。
