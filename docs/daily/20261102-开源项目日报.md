## 1. earendil-works/pi — Agent 工具包全家桶

**项目简介与定位**：一套用于构建和运行 AI Agent 的工具包（agent harness），包含自扩展的交互式编码 Agent CLI、统一的多供应商 LLM API、Agent 运行时和终端 UI 库。定位是"造 Agent 的材料库"——你既可以直接用它自带的编码 Agent，也可以拿它的包拼装自己的 Agent 产品。

**核心功能亮点**：
- **统一多供应商 LLM API**：一套接口切换 OpenAI/Anthropic/Google 等主流模型，免去各家居高不下的 API 差异适配；
- **自扩展交互式编码 Agent CLI**：Agent 可在运行中扩展自身工具集，是当前最受关注的 coding agent 底座之一；
- **Agent 运行时 + TUI 库**：把会话循环、工具调用、终端界面等通用件拆成独立包，按需取用；
- 模块化设计：每个能力（LLM 网关、循环、UI）都是独立 package，避免框架锁定。

**技术栈**：TypeScript / Node.js。

## 2. deepseek-ai/dsh-superagent-prototype — DeepSeek Super-agent 研究原型

**项目简介与定位**：DeepSeek Harness 团队 2026-10-31 刚开源的研究原型（README 首行即声明"仅供研究参考，非官方产品"），实现其技术文章《Super-agent 设计探索：迈向更自主的 Agent 系统》的配套参考实现：一个面向单个 GitHub 仓库的主动编码 Agent——监听 GitHub（可选飞书）事件，收到指令或命中团队规则时自动建工单、在独立会话与目录中完成编码并回发 PR。

**核心功能亮点**：
- **Router + Worker 双层架构**：Router 常驻全局节点统一接收入口消息并派活（可完全不配 Bash 工具），Worker 各持独立上下文与会话，互不干扰——把"会话管理"从人的注意力挪到系统层；
- **事件驱动 + 存算分离**：Engine 同步写领域状态，Store 用独立 SQLite，副作用走持久化 Effects 队列（事务内入队、提交后投递），是教科书级的 Agent 可靠性设计；
- **外部 Watchdog**：独立看门狗监督 Agent 行为，防失控；
- **注意力经济学**：设计原则直白——"尽可能少占用人的注意力，尽可能多交付价值"，只在有人必须行动时才发声。

**技术栈**：TypeScript；架构思想借自操作系统（调度、缓存、存算分离、看门狗）。

## 3. CopilotKit/OpenBot — 可审计的自托管 AI 同事平台

**项目简介与定位**：CopilotKit 开源的"AI 同事"平台（2026-08-19 发布）：每个 Bot 拥有一台真正属于自己的电脑——带独立登录态的 Chromium 容器、专属 `/workspace` 存储卷与 Shell（可选 gVisor 内核级隔离），所有浏览器/文件/命令/MCP 操作都必须经过唯一策略网关：先评估、再留审计、后执行。定位是 Grok Bot / Claude Cowork 的开源自托管替代。

**核心功能亮点**：
- **策略网关 fail-closed**：CEL 策略引擎可检查工具名、页面域名、命令、文件路径、MCP 工具、发起者身份等维度；deny 先于 allow 评估，缺策略则什么都不允许，规则损坏时拒绝而非放行——"没有不留下记录的操作路径"；
- **人工接管（Take the wheel）**：Bot 遇登录墙/2FA 时移交控制权给人，处理完交回，全程审计；
- **任意 AG-UI Agent 即 Bot**：LangGraph、Mastra、CrewAI、Pydantic AI、Google ADK 或手写端点都能接入，治理挂在协议层而非框架层；
- **组件化回复**：Bot 以沙箱编译的 React 组件而非纯文本作答，可在 /admin/playground 浏览器内起草发布；
- 企业就绪：SSO（Google/Microsoft/Okta/SAML/OIDC）、审计日志、连接器目录（Google Drive、Notion、Composio 数百 SaaS）、Helm Chart。

**技术栈**：Bun 1.3+ / TypeScript / Hono / React+Vite / PostgreSQL+pgvector / Docker（每 Bot 一容器）；协议为 AG-UI。

**适用场景**：企业想把"AI 同事"跑在自己基础设施上且必须通过安全团队审查的场景；为自研 Agent 补上治理/审计/人工接管层；对标商业 Agent Cowork 产品做私有化部署。

**可靠性评估**：8 个月 9.6k 星（月均 1.2k），50 名贡献者、昨日仍在推送、open issue 仅 87，CopilotKit 公司持续投入；MIT 许可无陷阱。两点保留：① 官方明示处于 Alpha，"是模板不是产品"，API 会动；② 持久化会话/记忆依赖 CopilotKit Intelligence（有免费档、可自托管，但属外部依赖）。

**上手建议**：Docker Compose 一键起，`.env` 里 `OPENBOT_SINGLE_USER=true` 可先以单管理员模式体验再开启登录；克隆后把 `examples/` 示例租户换成自己的 agents.yaml。生产使用前先在 /admin/boundaries 把 CEL 策略按最小权限收紧。

## 4. zeroclaw-labs/zeroclaw — Rust 自主 AI 助理基础设施

**项目简介与定位**：用 Rust 编写的"快速、小巧、完全自主"的 AI 个人助理基础设施：任何操作系统、任何平台皆可部署，模型/工具/存储皆可替换（swap anything）。目标是做一个长期在线、事件驱动的个人 Agent 运行时，而非一次性任务工具。

## 5. vercel-labs/agent-desktop — 桌面可靠操作层

**项目简介与定位**：Vercel Labs 出品的桌面 Agent 操作层：让任意 Agent 在桌面环境获得"可靠的计算机使用能力"。区别于像素截图匹配方案，它通过操作系统原生无障碍树（accessibility tree）读取任意应用的真实 UI 结构，用稳定引用（refs）定位元素、执行可重试的动作，跨平台支持 macOS / Windows / Linux，提供 CLI 与 C 库两种形态。

**核心功能亮点**：
- **a11y 树替代像素匹配**：读到的是真实 UI 语义结构而非屏幕像素，元素引用稳定，不因窗口缩放/主题变化失效，大幅降低 Agent 幻觉点击率；
- **可重试动作原语**：每个操作有明确成功/失败语义，Agent 可编程式重试而非盲目重截屏；
- **CLI + C 库双形态**：既可独立命令行驱动，也可嵌入其他 Agent 框架作为本地工具；
- 由 Vercel Labs 维护，与其 agent-browser（agent-browser.dev）生态互补，覆盖浏览器与桌面两端。

**技术栈**：Rust（CLI 与核心库）；Apache-2.0。

## 本期观察

1. **"Router 不动手"成为多 Agent 架构共识**：DeepSeek 的 Router 不配 Bash、只管派活；OpenBot 的网关只决策不执行——两家不约而同把"调度权"与"执行权"拆开，这与企业权限系统"审批与操作分离"同构。
2. **审计先于执行**：OpenBot（先评估留痕再调用）与 dsh-superagent（事务内入队、提交后投递 Effects）都在把 Agent 副作用变成"可回放的事件流"，Agent 可靠性工程正在系统化。
3. **a11y 树路线抬头**：agent-desktop 用无障碍树替代像素匹配，印证上一期趋势——Agent 与计算机的接口正从"看屏幕"升级为"读结构"。
